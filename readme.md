# The Internet Atlas

Explore, organize, and connect the websites and resources that make up the
internet.

## Overview

The Internet Atlas is a curated map of useful online destinations. It helps
people discover resources, understand how they relate to one another, and
navigate the web more intentionally.

## Features

- Curated internet resources
- Organized topics and categories
- Connections between related websites
- A simple foundation for community contributions
